M5ChainMIDI

AtomS3Rへブラウザからファームウェアを書き込みます。

このファームウェアは開発中のPreview版です Chain ToFを含む各デバイスの実機検証を進めています。動作確認への協力を目的とした公開版であり、正式版ではありません。

インストール

対応するAtomS3RをUSBデータケーブルでPCへ接続してください。

対応機種
M5Stack AtomS3R
構成
AtomS3R + Atomic ToChain Base
ファームウェア
M5ChainMIDI Preview
Web Serialに対応したデスクトップ版ChromeまたはEdgeで開いてください。 Web Installerを利用できない接続元です。HTTPSまたはlocalhostから開いてください。

書き込み中はUSBケーブルを抜かないでください。

実行前の確認

  • Arduino IDE、シリアルモニター、MIDIモニターなど、対象デバイスを使用するアプリを閉じてください。
  • USB充電専用ではなく、データ通信に対応したUSBケーブルを使用してください。
  • ポートが表示されない場合は、AtomS3R本体のボタンを押しながらUSBへ接続してください。
  • 接続先一覧では、書き込み対象のAtomS3Rを選択してください。

インストール後

  1. AtomS3Rが再起動するまで待ちます。
  2. PCのMIDIデバイス一覧にM5ChainMIDIが表示されることを確認します。
  3. Chainデバイスが画面上で正しく認識されることを確認します。
  4. MIDIモニターやDAWを使い、NoteおよびCCメッセージを確認します。
