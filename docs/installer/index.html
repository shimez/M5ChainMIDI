M5ChainMIDI

AtomS3Rへファームウェアを、ブラウザから簡単にインストールできます。

Stable version 1.0.0

M5ChainMIDIは個人が開発する非公式プロジェクトです。M5Stack Technology Co., Ltd.による公式製品ではなく、同社との提携または承認を示すものではありません。

Web Installer

AtomS3RをUSBデータケーブルでPCへ接続し、下のボタンから接続先を選択してください。

このブラウザはWeb Serialに対応していません。デスクトップ版ChromeまたはEdgeを使用してください。 Web Installerを利用できない接続元です。HTTPSまたはlocalhostから開いてください。
  1. AtomS3Rをデータ通信対応のUSBケーブルで接続します。
  2. 「Install M5ChainMIDI」を押し、AtomS3Rのシリアルポートを選びます。
  3. 画面の案内に従ってインストールを完了します。
  4. 再起動後、PCのMIDIデバイス一覧とAtomS3Rの画面を確認します。
ポートが表示されない場合は、AtomS3R本体のボタンを押しながらUSBへ接続してください。Arduino IDEやシリアルモニターなど、対象ポートを使用するアプリは事前に閉じてください。
